# Regia Asta — PWA

Carica nella root del repository GitHub tutti questi file e cartelle:

- index.html
- manifest.webmanifest
- service-worker.js
- icons/

Poi attiva GitHub Pages da Settings → Pages → Deploy from a branch → main → /(root).

Apri il link GitHub Pages dal telefono e usa “Aggiungi alla schermata Home” / “Installa app”.
